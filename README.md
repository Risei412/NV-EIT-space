# NV-EIT-space

Theory, proofs, and numerical verification for **electromagnetically induced
transparency (EIT) in solid-state defect centers** — starting from the NV
center in diamond and generalizing to a material-independent classification of
sector-mediated coherent response.

The work is organized as three successive theories, each with its own proof
document and its own reproducible numerical campaign:

1. **Binary no-go** — for NV centers, a transverse magnetic field opens a
   symmetry-suppressed Raman pathway quadratically (K ∝ B⊥²), producing an
   EIT-type response at finite temperature, while thermal dissipation
   suppresses it and defines a practical no-go boundary.
2. **Three-tier classification** — the binary go/no-go criterion is upgraded to
   an exclusive trichotomy of the suppression index ν ∈ {∞} ∪ (0,∞) ∪ {0}
   (exact structural no-go / asymptotic no-go / protected go) for
   finite-dimensional Markovian weak-probe systems. The theory and its
   material-independent campaigns are developed in a separate repository,
   [Sector-Master-Resolved-Theory](https://github.com/Risei412/Sector-Master-Resolved-Theory);
   what remains here are the NV-bound campaigns and the manuscript figures.
3. **Definition change** — EIT is redefined as *coherent cancellation in the
   observed response generated by the control field*, and the conditions
   equivalent to that definition are formulated and verified.

## Reproducing the numerics

Each theory directory is self-contained and pins its own dependencies:

```bash
# Binary no-go campaign
pip install -r "No-go theorem/requirements.txt"
python "No-go theorem/scripts/reproduce_prl_figures.py"

# Three-tier classification, NV-side campaigns
pip install -r "New no-go theory/requirements.txt"
python "New no-go theory/PhaseO_observable_inheritance/src/run_gate_a.py"

# PRL main-text figures
python "Writing Paper/prl_figures/src/make_figures.py"
```

Gate results are archived as JSON/CSV under each campaign's `results/`
directory, alongside the figures generated from them, so a run can be checked
against the recorded pass criteria without rerunning the full campaign. Tests
live in the `tests/` directory of each campaign and run with `pytest`.

## Conventions

- Every campaign writes a `gates_summary_*.json` recording each gate's numeric
  outcome and PASS/FAIL verdict; these are the authoritative results.
- Figures are committed alongside the code that produces them, so the figures
  in a manuscript can always be traced to a specific script and gate summary.
- Documents are in English or Japanese depending on the working stage; the
  proof documents (`Theorem and proofs/*.tex`) are English throughout.
