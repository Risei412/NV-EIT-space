# なぜNVセンターのEITは室温で消えるのか — 数値計算からの答え

> 研究室内共有用ドラフト（esa記事 #8 の改訂版、text_style_v1.md 準拠）
> 対象：実験メンバー。数式と定理は最小限とし、数値計算の結果を主に述べる。
> 数値の出典：`manuscript/main.tex`。特記なき限り、縮約を行わない完全なLiouvillian（以下、full Liouvillian）による9準位GKSL計算である。
> 固定パラメータ：$B\_z = 5\,\mathrm{mT}$、$\Omega\_c = 0.1\,\mathrm{GHz}$、横歪み $\delta = 1.683\,\mathrm{GHz}$、$D\_\mathrm{gs} = 2.877\,\mathrm{GHz}$

---

## 0. 先に結論

本ノートでは、窒素空孔中心（以下、NVセンター）における電磁誘起透明化（Electromagnetically Induced Transparency、以下 EIT）について述べる。対象は負電荷状態 NV$^-$ である。問いは、なぜ室温で観測できないかである。結論は次の $5$ 点である。

- 透明性が生じる領域は $(T, B\_\perp)$ 平面の閉じた島である。高温側だけでなく低温側も閉じる。
- 実用上限は $T\_{1\\%} = 74\,[70, 78]\,\mathrm{K}$ である。ここで $T\_{1\\%}$ は、コントラストが $1\\%$ を切る温度をいう。
- $103\,[97, 108]\,\mathrm{K}$ で応答が符号反転する。control光がprobeの吸収を増やす側に回る。
- 横磁場はスイッチであってダイヤルではない。経路を開くのに必須であるが、温度限界はほぼ動かせない（$0.15$ から $0.50\,\mathrm{T}$ で $2\,\mathrm{K}$ 未満）。
- 室温の残留コントラストは $1.1\times10^{-9}$ であり、検出限界の $9$ 桁下である。積算では届かない。

本ノートの構成は次のとおりである。第1節で問いを立て、第2節で微視的機構を述べる。第3節から第6節で各問いに答え、第7節で本理論が主張できない範囲を示す。

---

## 1. 本ノートが答える4つの問い

本ノートが答える問いは次の4つである。

1. なぜ室温のNVセンターではEITの観測が難しいのか。
2. 理論上のEIT観測限界温度はどれくらいか。
3. なぜアルカリ原子は室温でEITが観測できて、NVセンターは観測できないのか。
4. 横磁場は結局なにをしているのか。

以下、第2節で機構を述べる。その後、問い③、④、②、① の順に、第3節から第6節で扱う。

## 2. 微視的機構：軌道ホッピングはポピュレーションを保存したままコヒーレンスを殺す

本節では、温度上昇がEIT経路を壊す微視的な起源について述べる。まず軌道ホッピングの性質を示し、次にそれが光学コヒーレンスへ及ぼす効果を式で確認する。

NV$^-$ の励起状態 $^3E$ は $6$ 次元の軌道二重項である。温度が上がると、フォノン誘起の軌道ホッピング $E\_x \leftrightarrow E\_y$ が効いてくる。このホッピングは励起状態内でポピュレーションを移すだけであり、どこにも失っていない。

にもかかわらず、光学コヒーレンスに対しては純損失として効く。光学コヒーレンスのブロックを $\sigma = P\_e \rho P\_g$ と書くと、次式を得る。

```math
P_{e}\,\mathcal{D}[L_{\mu}](\rho)\,P_{g}
=-\tfrac12 L_{\mu}^{\dagger}L_{\mu}\,\sigma ,
\qquad L_{\mu}=P_{e}L_{\mu}P_{e}
```

右辺には recycling項 $L\rho L^\dagger$ が残っていない。この項は長方形ブロックを自分自身に繋げないためである。ゆえに軌道ホッピングは、励起状態のポピュレーションを保存したまま、Raman経路にとっては純粋なデコヒーレンス・チャネルとして働く。以上より、これが崩壊の微視的な起源であるといえる。

### 2.1 因子の取り扱い

対称な2方向ホッピング率を $k$ とすると、ポピュレーション不均衡の緩和率は $\Gamma\_{xy} = 2k$ である。一方、光学コヒーレンスの減衰率は $k/2 = \Gamma\_{xy}/4$ である。

上式に入るのは、通常の論文で引用される軌道緩和率の $1/4$ である。ここは繰り返しファクターエラーの原因になっている箇所であるため、実験メンバーは値を引くときに確認する必要がある。

### 2.2 「dephasingで薄れる」では説明にならない理由

よくある説明は、温度が上がるとdephasingが増えて特徴が洗い流される、というものである。これは誤りではないが不完全である。単調なフェードでは、次の3つを予言できない。

1. 下限温度の存在。
2. 横磁場の閾値の存在。
3. 応答の符号反転。

$3$ つとも実際に起きる。以下の節でその中身を述べる。

図$1$に、NV$^-$ のスピン-$\Lambda$ チャネルと、光学コヒーレンス減衰 $\gamma\_\mathrm{oc}(T)$ の横歪み分裂に対するスケール比較を示す。図$1$(a)より、光学双極子が軌道的であるため、$B\_\perp=0$ では $2$ 本の脚が直交スピン状態に終端し、主要Raman頂点が閉じることがわかる。

図$2$に、$B\_\perp = 0.232\,\mathrm{T}$ における吸収スペクトルを示す。実線が経路を残した応答 $A\_\mathrm{full}$、破線が経路を切った反実仮想 $A\_\mathrm{cut}$ である。図$2$より、$30\,\mathrm{K}$ では経路がセクター吸収をほぼ全部消すことがわかる。$70\,\mathrm{K}$ ではパーセント級の透明性が残る。$105\,\mathrm{K}$ では $2$ 本が交差済みであり、経路が吸収を足している。

## 3. 問い③：なぜアルカリ原子は室温で見えるのか

本節では、アルカリ蒸気とNVセンターの違いについて述べる。まず誤った対比を否定し、次に対称性による違いを示し、最後に本理論の式との対応を確認する。

本節はアルカリ蒸気に関する文献に基づく構造的説明である。アルカリ蒸気とNVセンターを同じ土俵で数値比較した計算は本リポジトリにない。参照する文献は次の3件である。

- **[C01]** Fleischhauer, Imamoglu, Marangos, *Rev. Mod. Phys.* **77**, 633 (2005)。標準3準位EIT、線形感受率、dark-state polariton の基準文献である。
- **[C04]** Mishina et al., *Phys. Rev. A* **83**, 053809 (2011)。アルカリ原子の多励起準位を扱い、Doppler広がり等の不均一広がりがEITを劣化させることを具体的に計算している。
- **[C09]** Fan et al., *Phys. Rev. A* **99**, 053821 (2019)。希土類固体において、不均一広がりを含むEITを扱っている。

ただし §3.4 のとおり、本理論の式から Mishina の感受率そのものを導出できることは確認済みである。

### 3.1 よくある誤った対比

「アルカリは不均一広がりだけだから平気であり、NVセンターはフォノンがあるからだめである」という対比がある。これは誤りである。

[C04] はまさに、多励起準位と不均一広がりが組むとEITが劣化することを計算している。不均一広がりは無害ではない。[C09] は希土類固体で同じ問題を扱っている。

ゆえに違いは不均一広がりの有無ではない。区別すべきは次の $2$ 種類である。

| | 不均一広がり（Doppler など） | 均一デコヒーレンス（NVセンターの軌道ホッピング） |
|---|---|---|
| 各エミッターの中では | コヒーレントであり、位相は決まっている | 光学コヒーレンスが純損失を受ける（第2節の式） |
| 消える理由 | アンサンブル平均で位相が散る | 経路そのものが減衰する |
| 回復可能性 | 配置と系列で部分的に回避しうる。co-propagating配置では一次Dopplerが二光子遷移で相殺され、基底コヒーレンスは残る [C01] | 回避できない。平均の問題ではない |

NVセンターの室温で効くのは下の行である。第2節の式が示すとおり、軌道ホッピングはポピュレーションを保存したまま光学コヒーレンスに純損失として入る。これは各NVセンターの内部で起きるため、サンプルを揃えてもエコーを打っても、経路自体が戻らない。

### 3.2 対称性による、より根本的な違い

温度以前の問題として、NVセンターでは経路が最初から対称性で閉じている。

|  | アルカリ蒸気 | NV$^-$ |
|---|---|---|
| $\Lambda$の2本の脚 | 同一の基底準位対に終端する。教科書どおりの3準位 [C01] | 光学双極子が軌道的である。$B\_\perp = 0$ では2本の脚が直交スピン状態に終端し、主要Raman頂点が恒等的にゼロになる |
| 励起状態 | 実効的に単一の微細構造準位で書ける。多準位が効く場合の劣化は [C04] | $6$ 次元の軌道二重項 $^3E$ である。分岐が複数あり、それらの間にフォノン結合がある |
| チャネルを持つ条件 | 特になし | $B\_\perp \gtrsim 0.15\,\mathrm{T}$ が必須である（第4節） |

### 3.3 2段構えの違い

以上より、アルカリ蒸気とNVセンターの違いは次の2段構えであるといえる。

1. アルカリ蒸気では経路がそもそも開いている。NVセンターでは対称性で閉じており、横磁場でこじ開ける必要がある（第4節）。
2. アルカリ蒸気で室温が持ち込むのは主に不均一広がりであり、配置で部分的に回避できる。NVセンターで室温が持ち込むのは均一なデコヒーレンスであり、経路そのものを殺すため回避できない（第2節）。

同じ $\Lambda$ 型の準位図でも、ある材料では深い透明窓が出て別の材料では何も出ない。これは、実在のエミッターが3準位描像に含まれない分岐、散逸チャネル、選択則を持つためである。

### 3.4 本理論の式から Mishina の感受率が導出できる

講義ノート `theory/proofs/eit_nogo_lecture.tex` の Theorem 2A は次式である。

```math
\Xi = S_1-\frac{\beta\,K_{12}K_{21}}{\gamma_g+\beta S_2},
\qquad
S_i=\sum_j\frac{|d_{ij}|^2}{a_j},
\quad
K_{ij}=\sum_j\frac{d_{ij}^{*}d_{jj'}}{a_j},
\quad
\beta=\frac{|\Omega_c|^2}{4}
```

この式から、Mishina et al. Eq. (2.11) の多励起準位感受率がそのまま出る。写像は $\Delta\_{e\_{F'}g} = i\,a\_j$、$\Omega\_c = 2\varepsilon\_c/\hbar$ である。

| Mishina Eq. (2.11) / (2.10) | Theorem 2A |
|---|---|
| 第1行 $\sum\_{F'}\|d\_{e\_{F'}g}\|^2/\Delta\_{e\_{F'}g}$ | $S\_1$ |
| 第2行の括弧の二乗 | $\beta K\_{12}K\_{21}$ |
| 第2行の分母 $\Delta\_{sg}$ | $i(\gamma\_g+\beta S\_2)$ |
| $\Delta\_{sg}$ 中の光シフト項 | $\beta S\_2$（符号も一致） |

すなわち $\chi = i\,(\rho^{(0)}\_{gg}n\_0/\hbar)\,\Xi$ である。Eq. (3.2) の Autler–Townes シフト $|\Omega^c\_{se\_2}|^2/(4\Delta\_D)$ も Theorem 2A の分母から直接出る。

物理的解釈も一致する。Mishina は「括弧内の二乗和は各$\Lambda$遷移の寄与が建設的にも破壊的にも干渉しうることを示す」と述べている。これは講義ノートの「Raman頂点は全分岐にわたる振幅のコヒーレント和 $K\_{12}=\sum\_j d\_{1j}^{*}d\_{2j}/a\_j$ である」と同一の主張である。

ただし一致は $\Lambda$ ブロックの範囲内である。Mishina の式のうち $N\_{e\_{F'}g}$、$\Delta N$、$-|\Omega^c\_{eg}|^2/(4\Delta\_{se})$ の各項は Theorem 2A に含まれない。これらは control が $|g\rangle\to|e\rangle$ を駆動する経路に由来する。ゆえに、Theorem 2A が仮定する閉じた2基底ブロックの外側にある。Mishina 自身も、これらを小さく解析に有意な役割を果たさない項としている。

以上より、感受率のレベルでは本理論とアルカリ原子の標準理論は接続しており、違いは経路の開閉と散逸の種類にあるといえる。

## 4. 問い④：横磁場はなにをしているのか

本節では、横磁場 $B\_\perp$ の役割について述べる。まず開口の冪指数を示し、次に実用上の結論を述べる。

### 4.1 経路を開く

$B\_\perp$ は基底スピン副準位を混ぜ、軌道双極子が供給できないスピン重なりを与える。混合が $\Lambda$ の各脚に $1$ 回ずつ入り、セクター媒介応答が $2$ つのRaman頂点について双線形である。ゆえに期待される振る舞いは次式である。

```math
C \simeq C_{\mathrm{res}} + a B_{\perp}^{\,n},
\qquad n = 2
```

ここで $C\_\mathrm{res}$ は、$^3E$ 内スピン混合を通る磁場に依らない残留経路である。

| 温度 | 結果 |
|---|---|
| $85\,\mathrm{K}$ | $n = 2.11 \pm 0.08$。カットオフを $0.022$ から $0.046\,\mathrm{T}$ と変えても $0.25$ しか動かず単調傾向なし（Spearman $\rho = -0.05$）。期待どおりの二次開口である |
| $70\,\mathrm{K}$ / $55\,\mathrm{K}$ | 指数が決まらない。カットオフとともに単調にドリフトする（$\rho = -0.97$）。最小カットオフでの $2.7$–$3.0$ から $B\_\perp \approx 0.04\,\mathrm{T}$ 付近で $2$ まで動く |

冪則ならフィット窓に対してプラトーが出る。クロスオーバーならまさにこのドリフトが出る。ゆえに $85\,\mathrm{K}$ 以上で二次であるとはいえるが、島の低温側では指数が決まらない。

これがフィットのやり方の問題でないことは、$2$ つのコントロールで確認済みである。第一に、control Rabi周波数を $0.03$ から $0.3\,\mathrm{GHz}$ と $10$ 倍振る。このとき $70\,\mathrm{K}$ の指数は $2.664$ から $2.628$ とほぼ動かない。第二に、磁場依存の分母を持たない絶対信号 $\Delta A = A\_\mathrm{cut} - A\_\mathrm{full}$ でフィットする。このときも $70\,\mathrm{K}$ で $2.70$ に対し $2.63$ と同じ指数が返る。

なお、フィット可能な磁場窓は両側から挟まれており $1$ 桁未満しかない。上限は摂動性の破れである。$\gamma\_e B\_\perp = D\_\mathrm{gs}$ となるのは $B\_\perp = 0.103\,\mathrm{T}$ であり、その $3$ 割の $0.031\,\mathrm{T}$ を天井に取る。下限は残留経路 $C\_\mathrm{res}$ から浮き上がる必要から $0.008\,\mathrm{T}$ 付近である。

### 4.2 スイッチであってダイヤルではない

実用上の結論は指数に依存しない。

| $B\_\perp$ | $T\_{1\\%}$ | $T\_\mathrm{sign}$ | 状態 |
|---|---|---|---|
| $\le 0.10\,\mathrm{T}$ | $27$–$33\,\mathrm{K}$ | $27$–$33\,\mathrm{K}$ | 両閾値が一致し、窓が存在しない |
| $0.15\,\mathrm{T}$ | $70.3\,\mathrm{K}$ | $98.5\,\mathrm{K}$ | 窓あり |
| $0.50\,\mathrm{T}$ | $69.7\,\mathrm{K}$ | $103.8\,\mathrm{K}$ | 窓あり |

磁場を $3.3$ 倍にしても $T\_{1\\%}$ は $0.6\,\mathrm{K}$ しか動かない。

図$5$に、セクターコントラストの $B\_\perp$ 依存性と、フィット上限カットオフに対する指数を示す。図$5$(b)より、$85\,\mathrm{K}$ はプラトーを示し、$70\,\mathrm{K}$ と $55\,\mathrm{K}$ はドリフトすることがわかる。冪則とクロスオーバーの違いがこの図で直接読み取れる。

![図5: セクターコントラストの $B_\perp$ 依存性とフィット上限カットオフに対する指数](https://raw.githubusercontent.com/Risei412/NV-EIT-space/main/results/figures/fig5_bperp_scaling.png)

以上より、横磁場はチャネルを持つために必要なだけであり、いったん開いたら境界を決めるのは散逸であるといえる。横磁場は抑制された応答の前置因子を変えるが、抑制が始まる温度は変えない。したがって、横磁場を高温EITの回復手段として設計してはならず、島の内側へ入るためのスイッチとして扱う必要がある。

## 5. 問い②：限界温度はどこか

本節では、透明性が存在する領域の境界について述べる。まず領域の形を示し、次に閾値の数値とコントラストの崩壊を示す。

### 5.1 透明性は島である

| 島の縁 | 位置 | 機構 |
|---|---|---|
| 磁場側 | $B\_\perp \gtrsim 0.15\,\mathrm{T}$ が必要 | 対称性による閉塞。横磁場が持ち上げるまでチャネルがない |
| 低温側 | $\sim 22\,\mathrm{K}$ 以下で閉じる | 散逸ではなく、Autler–Townesクロスオーバーである |
| 高温側 | $90$–$95\,\mathrm{K}$ で閉じる | フォノン駆動のRaman経路崩壊である |

低温側が閉じる理由は直感に反するため補足する。冷やすと光学線幅が狭くなる。このため、固定した control Rabi周波数 $\Omega\_c = 0.1\,\mathrm{GHz}$ が光学コヒーレンス減衰に対して相対的に大きくなる。ゆえに応答がAutler–Townes分裂（以下 ATS）の領域に入る。$20\,\mathrm{K}$ では、大きい磁場側で線形テストが頑健なATS判定を返し、小さい磁場側ではコントラストが負になる。$10\,\mathrm{K}$ では半値全幅 $\sim 70\,\mathrm{MHz}$ の広い構造が出るが、これは干渉窓ではなく dressed-state doublet である。

### 5.2 閾値の数値

$B\_\perp = 0.232\,\mathrm{T}$、full Liouvillian における Monte Carlo の $68\\%$ 区間は次のとおりである。

| 量 | 値 |
|---|---|
| $T\_{1\\%}$（コントラストが $10^{-2}$ を切る） | $74\,[70, 78]\,\mathrm{K}$ |
| $T\_\mathrm{sign}$（符号反転） | $103\,[97, 108]\,\mathrm{K}$ |

事前分布は次のとおりである。軌道ホッピング率スケールと輻射率スケールに対数正規、横歪みに正規、磁場2成分、基底デコヒーレンスに対数一様、control Rabi、偏光角誤差を置く。さらにレートスケールとは別に、スペクトル拡散を表す追加光学線幅に対数一様を置く。

フォノンレートモデル $4$ 種は、単一外挿ではなく離散的な系統誤差として扱っている。$4$ モデル間の広がりは $0.8$–$2.7\,\mathrm{K}$ であり、統計バンド $\sim 9\,\mathrm{K}$ の内側にある。ゆえに境界は単一の高温外挿に依存していない。

### 5.3 コントラストの崩壊

$B\_\perp = 0.232\,\mathrm{T}$ におけるコントラストの温度依存性を次表に示す。

| $T$ | コントラスト |
|---|---|
| $30\,\mathrm{K}$ | $0.99$ |
| $50\,\mathrm{K}$ | $0.58$ |
| $70\,\mathrm{K}$ | $1.4\times10^{-2}$ |
| $90\,\mathrm{K}$ | $1.5\times10^{-4}$ |
| $100\,\mathrm{K}$ | $2.1\times10^{-5}$ |
| これより高温 | 符号反転 |

## 6. 問い①：実験として実際に何が見えるか

本節では、コントラストを観測量へ変換した結果について述べる。まずサンプル条件を揃える必要性を示し、次に読み出し方式と必要積算時間を示す。

コントラストは観測量ではない。検出チェーンを通して初めて観測量になる。しかも全温度で同じチェーンを使わないと、物理ではなくサンプルを測ることになる。これは実際に危険である。光学線が狭くなるとセクター断面積が増えるためである。室温でほぼ透明なサンプル（光学密度 optical density、以下 OD で $\mathrm{OD} \approx 0.04$）は、$10\,\mathrm{K}$ では不透明（$\mathrm{OD} \approx 16$）になる。

そこで OD整合サンプル（$\mathrm{OD}\_\mathrm{sector} = 1$）を共通軸に取り、必要なサンプル長を併記している。

読み出しは $2$ つである。透過では $\Delta T/T = \mathrm{expm1}(\Delta \mathrm{OD})$、$\Delta\mathrm{OD} = \mathrm{OD}\_\mathrm{sector} \cdot C$ である。蛍光はNVセンターのアンサンブルでしばしば実用的であり、光学的に薄い極限で $\Delta\mathrm{PL}/\mathrm{PL} \to -C$ となる。すなわち透明性は同じ割合の蛍光のディップとして現れる。

ここでは、ショットノイズと相対technical noise floor $10^{-6}$ を仮定する。信号対雑音比（signal-to-noise ratio、以下 SNR）を $5$ とするのに必要な積算時間を次表に示す。

| $T$ | 透過信号 | 必要積算時間 |
|---|---|---|
| $70\,\mathrm{K}$ | $1.4\times10^{-2}$ | $\mathrm{\mu s}$ |
| $90\,\mathrm{K}$ | $1.5\times10^{-4}$ | $10\,\mathrm{ms}$ |
| $105\,\mathrm{K}$（反転後） | $-1.2\times10^{-5}$ | $1.6\,\mathrm{s}$ |
| $110\,\mathrm{K}$ | — | $5.6\,\mathrm{s}$ |
| $120\,\mathrm{K}$ 超 | — | 到達不能 |
| $300\,\mathrm{K}$ | $1.1\times10^{-9}$ | 検出限界の $9$ 桁下 |

表より、符号反転は数秒で測れる実測対象であることがわかる。一方、室温の残留は積算時間を延ばしても測れない。

蛍光は $105\,\mathrm{K}$ まで透過に追随し、その後に透過より先に落ちる。強く吸収するほど厚いサンプルでは、吸収のさらなる変化に対して蛍光が飽和するためである。

図$6$に、OD整合サンプルでの透過と蛍光の分数信号、および各読み出しでSNRを $5$ とするのに必要な積算時間を示す。積算時間は $24$ 時間で打ち切っている。

![図6: OD整合サンプルでの透過・蛍光の分数信号と必要積算時間](https://raw.githubusercontent.com/Risei412/NV-EIT-space/main/results/figures/fig6_observables.png)

### 6.1 決定的な実験

単一の温度と磁場で透明ディップが出ても、ほとんど何も確立できない。ディップはATSの兆候でもあるためである。

判別力があるのは次の $3$ つである。

1. 島の高温側での、横磁場に対する二次開口。
2. 温度に対するコントラストの数桁にわたる崩壊。
3. $103\,\mathrm{K}$ 付近の符号反転。ATS機構では出ず、かつ数秒で分解できる。

以上より、フリンジをゼロを通り越して反対側まで追う測定が決定的なテストになるといえる。第9節では、その測定を実際に組む際の論点を挙げる。

## 7. 本理論が主張できないこと

本節では、上記の数値を引用する際に必ず伴う制約について述べる。まずモデルの前提を示す。次に判定の一意性と数値モデルの系統誤差を述べる。さらに実験計画への含意、一般化の範囲、証明パッケージの状態、アルカリ原子との比較の位置づけを述べる。

### 7.1 モデルの前提

すべての主張は次の領域に条件づけられている。この外で引用したものは誤引用である。

- 有限次元、マルコフ的（時間非依存GKSL生成子）、弱プローブ（線形応答のみ）。
- 定常回転系、受動的な光学応答（利得なし）、一意な定常状態。
- 入力（source）と読み出し（readout）のチャネルが定義されていること。
- 物理的に指定された長寿命コヒーレンス・セクター $S$ が存在すること。

明示的に範囲外であるのは次のものである。強プローブ非線形性、非マルコフ的メモリ、連続体および伝搬不安定性、利得媒質、多体集団効果、時間依存フィードバック、Floquet駆動。

非マルコフ的なスペクトル拡散は、有効線幅の事前分布としてしか入っていない。記憶を持つバスとしては扱っていない。伝搬効果と集団効果は扱いの外である。

### 7.2 セクター切断と指数の帰属

no-go判定に使うセクター切断（sector cut）は、どのセクターを切るかという物理的な選択に依存する（T1 Lemma L1.2）。異なる切断を宣言すれば異なる結論になり得る。ゆえに no-go は常に、宣言した切断に対する言明であり、canonical ではない。

報告された指数は名指しされた観測量のものである。後段の規格化を変えると指数が変わる。指数の値を述べる前に、何の観測量の指数なのかを明示する必要がある。またセクターグラフ距離は応答次数の下限を与えるだけである。等号が成り立つには、主要経路の和がゼロにならないことが必要である。

### 7.3 数値モデルの系統誤差

第一に、reduced kernel の適用範囲が限られる。文献での見積もりの多く、そして本研究の不確かさ伝播も、励起多様体をresolventで縮約した核（reduced kernel）を使っている。full Liouvillian と $(T, B\_\perp)$ 平面の $108$ 点で比較した結果は次のとおりである。

| | 点数 |
|---|---|
| $10\\%$ 以内で一致 | $47 / 108$ |
| 符号が食い違う | $13 / 108$ |

しかも食い違いはランダムではなく構造的であり、$2$ 箇所に集中する。$40\,\mathrm{K}$ 以下では reduced が透明性を報告する（$20\,\mathrm{K}$ で $C \approx +0.99$）。一方 full は control誘起の吸収を報告する（$C \approx -1.5$）。すなわち符号が逆である。$90\,\mathrm{K}$ 以上では、どの磁場でも $10\\%$ 以内で一致しない。$T\_\mathrm{sign}$ がまさにここに座っている。

そのため reduced kernel は本研究では閾値の位置を出す目的にのみ使い、それも full model で独立に検証している。本ノートのコントラストの大きさはすべて full Liouvillian 由来である。

第二に、準位の打ち切りに起因する系統誤差がある。singletを $10$ 番目の準位として加えるか、$^{14}$N超微細多様体で平均を取る。このとき、ピークコントラストは $25$–$105\,\mathrm{K}$ の範囲で最大 $30\\%$ 変わる。符号は変わらない。ゆえにコントラストの絶対値は、この大きさの構造的系統誤差を持つものとして読む必要がある。境界温度と符号反転は影響を受けない。

### 7.4 光学NVセンターは自分の抑制指数を測れない

これは 2026-08-02 の監査結果である（`NON_CLAIMS.md` N2）。信号が漸近領域に入る前に検出限界へ達するため、指数のフィットに必要な $1$ 桁の窓が取れない。

| 条件 | 使える窓 |
|---|---|
| single | $1.02$ 桁 |
| post-selected shimmed | $0.84$ 桁 |
| high density | $0.51$ 桁 |
| 必要 | $1$ 桁 |

ゆえに、NVセンターで抑制指数を測って理論を検証するという実験計画は成立しない。測るべきは指数ではなく符号反転である（第6節）。

### 7.5 一般化と材料非依存性の範囲

group-IV（SiVセンター、SnVセンター）の曲線は定量的予言ではない（`NON_CLAIMS.md` N4）。フォノン正規化と双極子幾何が単一レートスケール、直交軌道基底の脚、$|M\_0|$ 正規化という概略的な設定であり、再フィットしていない。整数指数は影響を受けないが、絶対応答レベルは引用の対象としない。

また、工学的散逸プラットフォームを横断する測定可能な設計則、という一般形の主張は Gate E で棄却済みである（`NON_CLAIMS.md` N1）。$3$ プラットフォーム中 $2$ つが失敗している。生き残っているのは 3-mode engineered-loss chain に関する狭い主張だけであり、それも実証されていない設計仮定に条件づけられたモデルレベルのものである。

### 7.6 証明パッケージの文書上のギャップ

- T1 の Theorem 2.1 は本リポジトリでは証明されていない。別パッケージから逐語的に適用している。
- Theorem 2.2 の反例の数値を生成するコードが本リポジトリにない。
- Theorem 2.3(ii) の generic の意味が定義されていない。現状で防御可能な形は、単一Lorentzian極を持つ受動応答である。
- v7 の singular-damping 定理は Hermitian 半正定値 $D$ に対して証明されたものであり、一般の非正規への拡張を含まない。

### 7.7 アルカリ原子との比較の位置づけ

第3節について、いえることは次のとおりである。§3.4 のとおり、本理論の Theorem 2A から Mishina Eq. (2.11) の多励起準位感受率を導出できる。Eq. (3.2) の Autler–Townes シフトも分母から出る。

一方、いえないことは次の $3$ 点である。

1. Theorem 2A は $\Lambda$ ブロックの外側の経路を含まない。Mishina の $N\_{e\_{F'}g}$、$\Delta N$、$-|\Omega^c\_{eg}|^2/(4\Delta\_{se})$ は対象外である。これらは control が $|g\rangle\to|e\rangle$ を駆動する寄与である。
2. アルカリ蒸気とNVセンターを同じ土俵で数値比較した計算は本リポジトリにない。
3. §3.1 の「不均一広がりと均一デコヒーレンスの区別」は本理論の言葉での整理であり、その形で検証された命題ではない。

以上より、本ノートの数値のうち、full Liouvillian による島の境界と符号反転は引用に耐えるといえる。絶対応答レベル、抑制指数、材料横断の一般則は引用の対象としない。第9節の議論では、この境界の内側で測定を設計する必要がある。
