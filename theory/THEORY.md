# THEORY.md — what the theory says

The explanatory entry point. Symbols are in `DEFINITIONS.md`, statements in
`THEOREMS.md`, arguments in `PROOFS.md`, the regime of validity in
`ASSUMPTIONS.md`, and the regime where it does not hold in `LIMITATIONS.md`.

## The question

EIT in solid-state defect centers is conventionally diagnosed by the presence
of a **dark state**. That diagnosis is structural: it asks whether a state
exists that the drive cannot reach. It says nothing directly about what a
probe *measures*, and it does not survive contact with dissipation-dominated
solid-state systems, where the relevant subspaces are neither exactly dark nor
cleanly separable.

This repository replaces the dark-state diagnosis with a **response-theoretic**
one.

## The move

Transparency is defined as *coherent cancellation in the observed response
generated by the control field*. The object that carries the statement is the
**sector cut**

    Δχ_S := χ − χ^(S)_cut ,

the difference between the full linear response and the response with the
long-lived coherence sector `S` cut out. The cut, not the full response, is
what a no-go statement must be made about: `χ_full = 0` is *not* a no-go
(Theorem 2B). A system can change class in a way that is completely invisible
in the total spectrum and visible only in `Δχ_S` — the *hidden class
transition*, confirmed numerically in Phase B.

## The classification

Systems are classified by how fast the sector-mediated response is suppressed
as the fast-dissipative scale `Γ` grows:

    ‖Δχ_S‖ ~ Γ^(−ν) ,    ν ∈ {∞} ∪ (0,∞) ∪ {0}

and the three cases are exclusive:

| `ν` | Class | Meaning |
|---|---|---|
| `∞` | I — exact structural no-go | Cancellation is exact and structural (selection rule / symmetry); every moment vanishes. |
| `(0,∞)` | II — asymptotic no-go | Suppressed as a power of `Γ`; the exponent is an *integer* fixed by the first nonvanishing moment. |
| `0` | III — protected go | A protected channel survives; the response plateaus instead of decaying. |

Because the exponent is integer-valued and set by the first nonvanishing
moment (Theorem 3) or by an exact transfer zero (Theorems 4–6), the
classification is material-independent: the same three tiers appear in NV, in
group-IV color centers, and in an engineered-loss superconducting chain.

## The mechanism result

For a passive coherence block `A(δ) = Γ + i(H − δI)` with `Γ = Γ† ≥ 0`,
**matched** readout (source = readout) obeys

    Re χ_matched = x†Γx ≥ 0 .

This is an identity, not a numerical search result. An exact zero requires
`x ∈ ker Γ`, which matched readout cannot reach. The only escape is
**unmatched** readout — and F5B does find exact zeros in Raman-basis coherence
readout. Characterizing that escape route in general is an open question
(`NEXT_GATES.md` O4).

## Where the theory bites, and where it stops

The classification is a *structural* statement and is believed established.
Whether it is an *experimentally* meaningful one is a separate question, and
the answer so far is largely negative: Gate E found that optical NV — the
platform the theory was built for — cannot have its exponent read at all,
because the signal reaches the detection floor before the asymptotic regime
begins. The general "measurable design rule" claim does not survive; a
3-mode engineered-loss chain survives conditionally. See `CLAIMS.md` and
`NON_CLAIMS.md`, which are the binding versions of this paragraph.
