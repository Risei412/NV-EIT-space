# LIMITATIONS.md — where it does not hold

Known failures, gaps and non-results. This file is a primary asset, not an
apology: everything here was found by a gate or an audit and is what keeps
`../CLAIMS.md` narrow.

## Experimental limits

### Optical NV cannot resolve its own exponent

The single most important finding of the 2026-08-02 audit (G-D7 slope budget).
The signal reaches the detection floor before the asymptotic regime begins:

| Configuration | Usable window (decades) | Required |
|---|---|---|
| single | 1.02 | 1 |
| post-selected shimmed | 0.84 | 1 |
| high density | 0.51 | 1 |

The platform the theory was built for is therefore not a platform on which the
theory's central quantity can be measured.

### Gate B's experimental window is unresolved

At realistic `κ` the effective exponent is ≈ 0 at 0.1–50 MHz for both generic
and protected cases; integer asymptotics are readable only 8+ orders above
physical bath damping. Gate B supports structural universality, not a
measurement procedure for that device.

### The measurable-design-rule claim does not survive

Requiring `I_E = I_engineerable ∩ I_asymptotic ∩ I_detectable` to be
non-empty: optical NV FAIL, Gate B SC transfer FAIL, 3-mode chain model-level
conditional PASS. See `../NON_CLAIMS.md` N1.

## Theory-side gaps

### Theorem 1B's proof has an unwritten step

"A short rearrangement shows this equals …" hides a real subtlety:
`L_μ|D⟩ = λ_μ|D⟩` gives `ρ_D L_μ† = λ_μ* ρ_D` but **not**
`ρ_D L_μ = λ_μ* ρ_D`. A route via `H_eff := H − (i/2) Σ_μ L_μ†L_μ` avoids it.
The theorem is believed correct; the written proof is incomplete.

### T1 Theorem 2.1 is not proved in this repository

It is applied verbatim from a package that is not present here. Theorem 2.2's
counterexample numbers are generated by no code in this repository either.

### T1 Theorem 2.3(ii)'s genericity is undefined

Argued for a single Lorentzian pole, asserted for "generic `K(z)`" with no
definition of the dense set. Either the claim weakens to "any passive response
with a single Lorentzian pole", or genericity gets defined.

### The sector cut is not canonical

By T1 Lemma L1.2 the cut depends on the physical choice of sector `S`. Two
defensible sector choices give two different `Δχ_S`, and therefore two
different class assignments. The choice must be stated with the result.

## Method-level lesson (kept deliberately)

F5B concluded "no counterexample" from 150 random draws — the weakest possible
evidence for a positivity claim — and had come within two implementation bugs
of reporting the wrong conclusion. F5C replaced the scan with a one-line
identity proof. Random scans are not accepted as evidence for positivity
claims in this repository.
