names the strength it is asserted at and the artifact that carries it.
Anything not listed here is not a claim of this repository — see
`NON_CLAIMS.md`.

## C1 — Exclusive trichotomy of the suppression index (structural)

**Strength:** believed established.

For finite-dimensional Markovian weak-probe systems the suppression index
`ν ∈ {∞} ∪ (0,∞) ∪ {0}` obeys an exclusive trichotomy: exact structural no-go
(`ν = ∞`), asymptotic no-go (`ν` finite and positive), protected go (`ν = 0`).

**Evidence:** `theory/proofs/eit_nogo_proofs.tex` (Theorems 3, 4, 6);
`results/certificates/gates_summary_phaseA.json`,
`gates_summary_phaseB.json`.

## C2 — The sector cut is the correct object of a no-go statement (structural)

**Strength:** believed established.

The object a no-go statement must be made about is the sector cut
`χ − χ^(S)_cut`, not the full response: `χ_full = 0` is not a no-go
(Theorem 2B note). A hidden class transition is invisible in the total
spectrum and is detected only via the full-cut difference.

**Evidence:** `theory/proofs/eit_nogo_proofs.tex` (Theorem 2B);
`theory/proofs/T1_sector_cut_axiomatization.tex`;
`results/certificates/gates_summary_phaseB.json` (Gate 2, hidden class
transition).

## C3 — Matched-readout transparency has an identity floor (mechanism)

**Strength:** believed established (newer than C1–C2).

For a passive coherence block `A(δ) = Γ + i(H − δI)` with `Γ = Γ† ≥ 0`,
matched readout obeys `Re χ_matched = x†Γx ≥ 0`. This is an identity, not a
search result. An exact zero requires `x ∈ ker Γ`, which matched readout
cannot reach; the only escape is unmatched readout (source ≠ readout).

**Evidence:** `gates/closed/F5C_findings.md`;
`results/certificates/gate_F5C_matched_floor_accretive.json`;
`results/certificates/gate_F5B_full_gksl.json`
(`min_Re_chi_matched = +0.012866` at `delta = -6.0`,
`any_gain_in_matched = false`).
