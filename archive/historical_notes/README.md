## The 2026-08-13 restructure

The repository was reorganized from campaign-shaped directories
(`No-go theorem/`, `New no-go theory/`, `EIT definition equivalence/`,
`Writing Paper/`, …) into the canonical theory-repository layout: claims and
state at the root, `theory/`, `calculations/`, `results/`, `gates/`,
`evidence/`, `literature/`, `manuscript/`, `provenance/`, `archive/`.

Two consequences worth remembering:

- Campaign code kept its internal structure, but **outputs moved out** to a
  flat repository-level `results/` tree, split by artifact kind rather than by
  campaign. All output filenames were already distinct across campaigns, which
  is what made the flat layout safe.
- Path constants in the runners and tests were rewritten accordingly. The full
  suite (70 tests) passes after the move, and the PRL figures regenerate
  identically.
