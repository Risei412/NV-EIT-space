# Gate F5-C 結果 — matched floor をランダム走査から恒等式 + 敵対的探索へ

実行日 2026-07-31。スクリプト: `src/matched_floor_accretive_gate.py`。
機械可読出力: `results/gate_F5C_matched_floor_accretive.json`。

## 0. このゲートを作った理由

`F5B_findings.md` は matched response のフロアを **150 回のランダム抽出**
(`min Re χ_matched = 0.0029`) で「反例なし」と結論している。
これは no-go 型の主張に対する証拠としては最も弱い形である。正値性の主張は
最悪ケースの強さしか持たないが、ランダム抽出は最悪ケースを探していない。
しかも F5B 自身が、実装バグ2件(kron 引数順・線形応答の符号)によって
**誤った結論を報告する一歩手前だった**と記録している。乱数走査に依存した
主張は、その依存自体を切るべきである。

F5-C はモデル境界の両側で証拠を置き換える。

## 1. Part 1 — 定理が効く領域(縮約コヒーレンスブロック): 一行の証明

F0/F1/F4 が使う受動的コヒーレンスブロック

```
A(δ) = Γ + i (H − δ I),    Γ = Γ† ≥ 0,   H = H†
```

に対し matched 応答は `χ = e†A⁻¹e`(source = readout = e)。`x = A⁻¹e` と置くと
`e = A x` なので

```
χ = (A x)† x = x† A† x = x† Γ x − i x† (H − δI) x
⇒  Re χ_matched = x† Γ x ≥ 0,
```

`Γ > 0` なら狭義正。**F4/F5B の「透明化フロア」は探索結果ではなく恒等式**である。

さらにこの式は *どこで破れうるか* まで指定する: 厳密零点には `x ∈ ker Γ` が
必要であり、matched 読み出しでは起こらない。逃げ道は source ≠ readout
(unmatched)しかない。これは F5B が Raman 基底コヒーレンス読み出しで
実際に厳密零点を見つけた事実と正確に整合する — 偶然ではなく、
恒等式が許す唯一の場所で見つかっていた。

### 数値検証(4000 試行、2〜5 次元、ランダム `Γ = GG† ≥ 0`、ランダム `H`)

```
max relative deviation from the identity : 9.24e-15   (機械精度)
min Re χ over trials, Γ > 0              : 2.23e-03   (>0)
min Re χ over trials, Γ singular         : 1.61e-04   (≥0)
verdict                                   : PASS
```

`Γ` の最小固有方向を射影して特異にした場合も `Re χ ≥ 0` は破れない
(等号には `x` がちょうど kernel に入る必要があり、ランダムには起きない)。

## 2. Part 2 — 定理が効かない領域(ポピュレーション込み完全 GKSL)

完全密度行列応答は `e†A⁻¹e` の形をしていないので、Part 1 の恒等式は移らない。
そこがまさに F5B がランダム走査に頼った領域である。Part 2 は同じ rate floor
(`γ_g, γ_relax ≥ 10⁻³`)の下で

```
目的関数 = min_δ Re χ_matched / max_δ |Re χ_matched|
```

(スケールで正規化してあるので、応答全体を小さくすることで「勝つ」ことはできない)
を Nelder-Mead 多点再スタートで **能動的に最小化**する。
ランダム 150 点の `0.0029` を方向探索が下回れるかを直接問う設計であり、
下回って負に達すれば完全 GKSL でのフロア反例、達しなければランダム走査より
遥かに強い証拠になる。どちらに転んでも情報がある。
